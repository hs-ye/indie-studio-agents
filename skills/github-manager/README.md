# GitHub Manager Skill

The GitHub Manager skill provides standardized GitHub operations for all agents to manage issues, projects, and development workflows through GitHub CLI.

## Purpose
Enable all agents to interact with GitHub repositories, manage issues, track work through projects, and coordinate development activities using consistent commands and patterns.

## Key Functions
- Project board status management
- Issue creation and updates
- Pull request handling
- Standardized commenting and labeling
- Workflow coordination through GitHub
